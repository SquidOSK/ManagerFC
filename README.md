# Manager FC para Chromebook

Este é um PWA (Progressive Web App), portanto funciona no Chrome e pode ser instalado como aplicativo no Chromebook.

1. Publique estes arquivos em um endereço HTTPS (GitHub Pages, por exemplo).
2. Abra o endereço no Chrome.
3. No menu do Chrome, selecione **Instalar Manager FC**.
4. O jogo passa a aparecer como aplicativo.

O progresso é salvo automaticamente no navegador.
